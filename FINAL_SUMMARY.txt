🔧 TROUBLESHOOTING QUICK GUIDE
══════════════════════════════════════════════════════════════════════════════

"No module named pigpio"
  → Activate venv: source bin/activate
  → Install: pip install pigpio

"Cannot connect to daemon"
  → Start daemon: sudo systemctl start pigpiod
  → Or restart: sudo systemctl restart pigpiod

"Permission denied"
  → Make sure venv is activated first

"daemon won't start"
  → Check if running: ps aux | grep pigpiod
  → Check status: sudo systemctl status pigpiod

"GPIO not accessible"
  → Daemon must be running: sudo systemctl status pigpiod
  → May need: sudo usermod -a -G gpio $USER

For detailed troubleshooting, see:
  → INSTALLATION_COMPLETE.md (Troubleshooting section)
  → PIGPIO_INSTALLATION.md (FAQ and troubleshooting)
