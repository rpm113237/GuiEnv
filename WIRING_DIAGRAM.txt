╔════════════════════════════════════════════════════════════════════════════════╗
║                     PHYSICAL WIRING CONNECTION GUIDE                            ║
╠════════════════════════════════════════════════════════════════════════════════╣
║                                                                                 ║
║  1. CONTROL SIGNALS (Raspberry Pi → BTS7960)                                   ║
║     ┌──────────────┬────────────┬──────────────────────────────────┐           ║
║     │ Raspberry Pi │ BTS7960    │ Wire Color                       │           ║
║     ├──────────────┼────────────┼──────────────────────────────────┤           ║
║     │ GPIO 23      │ IN1        │ Green or Yellow                  │           ║
║     │ GPIO 24      │ IN2        │ Green or Blue                    │           ║
║     │ GPIO 25      │ EN         │ White or Gray                    │           ║
║     │ GND          │ GND        │ Black (Common Ground)            │           ║
║     └──────────────┴────────────┴──────────────────────────────────┘           ║
║                                                                                 ║
║  2. POWER CONNECTION (External Power Supply)                                   ║
║     ┌───────────────┬────────────┬──────────────────────────────────┐          ║
║     │ Power Supply  │ BTS7960    │ Wire Gauge (Amperage)           │          ║
║     ├───────────────┼────────────┼──────────────────────────────────┤          ║
║     │ +12V/+5V      │ +5V In     │ Red (16-20 AWG for ≤5A)         │          ║
║     │ GND/COM       │ GND        │ Black (16-20 AWG for ≤5A)       │          ║
║     │ Fuse (10-20A) │ Inline    │ 1A-2A per motor amperage        │          ║
║     └───────────────┴────────────┴──────────────────────────────────┘          ║
║                                                                                 ║
║  3. MOTOR CONNECTION (BTS7960 → DC Motor)                                      ║
║     ┌─────────────┬────────────┬──────────────────────────────────┐            ║
║     │ BTS7960     │ Motor      │ Note                             │            ║
║     ├─────────────┼────────────┼──────────────────────────────────┤            ║
║     │ OUT1        │ Terminal+  │ Thicker wire if high current     │            ║
║     │ OUT2        │ Terminal-  │ (match motor amperage rating)    │            ║
║     │ GND         │ Case/Shield│ Optional shielding for EMI       │            ║
║     └─────────────┴────────────┴──────────────────────────────────┘            ║
║                                                                                 ║
║  WIRING TIPS:                                                                   ║
║  • Keep control signal wires (GPIO) short and together                         ║
║  • Use separate twisted pair for each GPIO signal                              ║
║  • Keep power wires separate from signal wires (minimize EMI)                  ║
║  • Use ferrite clamps around signal cables if getting interference              ║
║  • Double-check polarity before connecting power                               ║
║  • Use quality connectors to prevent loose connections                         ║
║                                                                                 ║

MOTORCONTROL SIGNAL SEQUENCE EXAMPLE:
══════════════════════════════════════

Time  Sensor(SF)  Target(TGT)  Delta(SF-TGT)  Action           Motor Speed
─────  ──────────  ──────────  ─────────────  ──────────────── ─────────────
0s     45.0        50.0        -5.0           Reverse active   50%
1s     46.0        50.0        -4.0           Reverse          40%
2s     47.0        50.0        -3.0           Reverse          30%
3s     48.0        50.0        -2.0           Reverse          20%
4s     49.0        50.0        -1.0           Reverse          10%
5s     49.8        50.0        -0.2           Reverse (slow)   2%
6s     50.1        50.0        +0.1           Forward (slow)   1%
7s     50.0        50.0        0.0            STOP             0% (Motor Off)
8s     50.0        50.0        0.0            Idle             OFF

Sensor reading moves from 45 toward target of 50.
Motor runs in reverse to increase sensor value.
When delta is within tolerance (±5), motor stops.
Application proceeds to next calibration step.


FORMAT QUICK REFERENCE:
══════════════════════════════════════════════════════════════════════════════════
GPIO Signal Levels:  HIGH = 1 = 3.3V  |  LOW = 0 = 0V
PWM Duty Cycle:      0-100%  (0-100% power delivery)
Frequency:           1000 Hz (1000 cycles per second)
Motor Response:      Direction changes in ~1-2ms
                     Speed changes in ~1-5ms (depends on motor inertia)
Sensor Read Interval: 500ms (every half second during AutoSendLoop)
Timeout:             60 seconds maximum wait per calibration step
